# PortafoliosGrupalBitwars_v3

Proyecto Vue 3 + Vite con:
- estilo 16-bits
- partículas azules/violetas flotando en todas las secciones
- logo B grande (pixel SVG)
- sin sonido
- animacion de explosion de pixeles al click (DOM)

## uso
1. instalar dependencias:

```
npm install
```
2. levantar dev server:

```
npm run dev
```

Reemplazá las fotos y datos en `src/components/Home.vue` y los links en `src/components/Contact.vue`.
